# Contributing to Bilt MCP Server Documentation

Thank you for your interest in contributing! This repository contains documentation and examples for the Bilt MCP Server.

## What You Can Contribute

- 📝 Documentation improvements
- 💡 Additional examples
- 🐛 Bug reports (documentation issues)
- 🔧 Integration guides for new MCP clients
- 💬 Better explanations

## How to Contribute

1. **Fork the repository**
2. **Create a branch:** `git checkout -b feature/your-improvement`
3. **Make your changes**
4. **Test examples** (if applicable)
5. **Commit:** `git commit -m "Add: your improvement"`
6. **Push:** `git push origin feature/your-improvement`
7. **Open a Pull Request**

## Guidelines

### Documentation

- Use clear, concise language
- Include code examples where helpful
- Test all configuration examples
- Follow existing formatting style

### Examples

- Provide complete, working examples
- Include expected output
- Add comments explaining key steps
- Test with actual MCP clients

### Code Style

- Use 2 spaces for indentation
- Format JSON properly
- Include helpful comments

## Reporting Issues

Found a problem with the docs? [Open an issue](https://github.com/buildingapplications/mcp/issues/new)

Include:
- What you expected
- What actually happened
- Steps to reproduce
- Your environment (OS, MCP client, etc.)
